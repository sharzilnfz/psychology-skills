# Module 20: Triggers Map

**Goal:** Identify triggers, high-risk situations, and behavioral chains.

## Trigger Categories

| Category | Examples |
|----------|---------|
| **Negative emotions** | Anger, anxiety, depression, boredom, loneliness |
| **Social pressure** | Being around users, peer pressure, celebrations |
| **Interpersonal conflict** | Arguments, rejection, criticism |
| **Positive emotions** | Celebration, excitement ("I can handle it now") |
| **Testing control** | "Let me see if I can have just one" |
| **Urges/cravings** | Physical or psychological pulls without clear trigger |
| **Environmental** | Places, times, routines associated with use |

## Chain Analysis (CBT)

For the top 3 triggers:
1. **Trigger:** What happened?
2. **Thought:** What went through your mind?
3. **Craving:** What did the urge feel like physically?
4. **Permission-giving thought:** "Just this once" / "I deserve it" / "It's not that bad"
5. **Behavior:** What did you do?
6. **Consequence:** Immediate AND delayed
7. **Alternative:** At what point could you have done something different?

## HALT Check

When craving hits, check: Am I **H**ungry, **A**ngry/Anxious, **L**onely, **T**ired?

## Saturation

Top 5 triggers mapped with full chains + HALT awareness.
