# Module 30: Values Discrepancy (Contemplation)

**Goal:** Explore ambivalence. Develop discrepancy between behavior and values.

## Decisional Balance

```
┌──────────────────────┬──────────────────────┐
│  PROS of current     │  CONS of current     │
│  behavior            │  behavior            │
│  (what it gives)     │  (what it costs)     │
├──────────────────────┼──────────────────────┤
│  PROS of changing    │  CONS of changing    │
│  (what I'd gain)     │  (what I'd lose)     │
└──────────────────────┴──────────────────────┘
```

## MI Techniques

- **Evoking change talk:** "What would be different if you changed?"
- **Developing discrepancy:** "You said family matters most. How does
  [behavior] fit with that?"
- **Exploring ambivalence:** "Part wants to change, part doesn't. What
  does each part need?"

## IFS Parts Work

- "Is there a part that wants to keep using? What is it afraid would happen
  if you stopped?"
- "Is there a part that wants to change? What does it hope for?"
- "What would your Self say to both parts?"

## CFT for Shame

- "The part that uses is not bad — it is trying to meet a need. Can you
  hold compassion for that part while also exploring change?"

## Values Discrepancy

- "What matters most to you in life?"
- "Where is the gap between who you want to be and what's happening?"
- "Importance of change (1-10)? Confidence you could (1-10)?"

## Saturation

User articulates their own reasons for change (not yours). Decisional
balance completed. Change talk emerging.
