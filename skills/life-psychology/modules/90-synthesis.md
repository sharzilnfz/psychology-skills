# Module 90: Synthesis

**Goal:** Compile a complete life direction profile.

## Pre-Synthesis Quality Gate

- Did I generate synthetic meaning or toxic positivity? If yes, discard.
- Did I use Socratic dialogue to let the user excavate their own values?
- Did I maintain trauma-informed principles (no forced exploration)?
- Did I respect cultural context?
- Did I adapt to the user's reported processing preferences?

## Compiled Profile

1. **Life Audit Snapshot** (domain scores + severity)
2. **Transition Arc Position** (endings / neutral zone / new beginnings)
3. **Dominant Narrative + Alternative Stories** (named + re-authoring direction)
4. **Core Values** (3-5 with examples, conflicts, inherited vs. chosen)
5. **Meaning Sources** (creative, experiential, attitudinal)
6. **Active Experiments** (2-4 with observation criteria)
7. **Maintenance Plan** (meaning practices + transition resilience)
8. **Readiness Trajectory** (trend, victory log, patterns)
9. **Growth Edges** (where the real work continues)
10. **Questions Still Open** (and that is OK)
11. **Situational Work** (if explored: grief processing, decision architecture)

## After Synthesis — Write Outputs (MANDATORY)

IMMEDIATELY after compiling the profile:

1. **Write `90_SYNTHESIS.md`** to the session directory containing the
   complete compiled profile (all 11 sections above)
2. **Update `profile.json`** with ALL durable data:
   - `coreValues` — finalized with evidence
   - `recurringPatterns` — all observed patterns
   - `strengths` — specific, evidenced strengths
   - `longitudinal.readinessTrajectory` — final data point
   - `longitudinal.victoryLog` — all victories
   - `longitudinal.sessionCount` — increment
3. **Update `state.json`**:
   - Set `currentPhase` to `80-maintenance`
   - Schedule first booster (default: 30 days)
4. **Verify completeness**: Every module in `completedPhases` MUST have
   a corresponding module output file
