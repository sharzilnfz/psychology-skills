# State Summary Schema

`state-summary.json` is a compact (~2KB) digest of the full session state,
generated by `scripts/compact.mjs`. It is the **first file loaded** at session
start, enabling tiered loading.

## Schema

| Field | Type | Description |
|-------|------|-------------|
| niche | string | Active niche |
| sessionNumber | number | Current session count |
| currentPhase | string | Active module phase |
| nextPhase | string | Next module in path |
| activeThreadCount | number | Count of unresolved open threads |
| pendingCommitments | string[] | Text of pending commitments only |
| topInsights | string[] | Last 3 key insights |
| activePatternIds | string[] | IDs of active recurring patterns |
| riskLevel | number | Current risk assessment |
| stageOfChange | string | Current stage |
| lastCompacted | string | ISO-8601 timestamp of last compaction |
| lastUpdated | string | ISO-8601 from state.json |
| tokenEstimate | number | Estimated tokens for full state load |

## Usage

The agent loads `state-summary.json` at session start for bridge context.
Full `state.json` and `profile.json` are loaded on-demand when deeper
history is needed.
